# 试点验证方案（模板）

- 编写日期：2026-09-03（按产品最新定位修订）
- 使用说明：本文档是**方案模板**。所有标注「待填写」「待确认」的位置在试点真实启动前由团队与试点单位共同填写；当前不存在任何已签署的合作、访谈或数据，不得在答辩中表述为已完成事项。

## 1. 产品定位、用户与切入场景

### 1.1 产品定位

供需透镜是**面向工业园区与制造企业的再生材料供需匹配和净减排决策系统**：把园区内外分散的可利用余料、再生材料供给与企业替代需求连接起来，在规格、数量、时窗、价格和运输约束下，给出可落地的匹配/组合方案，并计算资源循环量、净减排量与绿色成本。

首个切入与演示场景：**非食品接触类工业包装/周转制品使用再生 PP 颗粒替代原生 PP**。

### 1.2 客户与使用者

- **首要客户/付费方：工业园区管委会、园区运营公司或循环化改造服务商**——它们需要组织企业间供需对接、提高园区资源循环利用率并形成可追溯成效。
- 首要使用者：产废/供料企业的环保与销售人员、用料企业的采购与工艺人员、园区绿色低碳运营人员。
- 次级客户：再生资源平台、绿色供应链服务商、需要提高再生材料使用比例的制造企业。

### 1.3 一次完整用户任务（六步）

1. 导入一条物料需求（如再生 PP 颗粒替代需求），以及若干供给方的物料类别、成分/性能、数量、可用时间、位置、价格和证据；
2. 设置不可突破的规格、质量、安全、数量和交付约束，再设置成本、就近利用和减排偏好；
3. 先做可替代性门槛判断，排除不满足硬约束的物料，并列出需要取样检测或补充的证据；
4. 对可行供给做单一匹配或多供方组合，返回非支配方案，不武断给一个「AI 最优解」；
5. 对每个方案计算材料循环利用量、原生材料替代量、运输与预处理排放、避免处置和避免原生材料生产的排放、净减排量、成本变化及供应集中风险；
6. 导出一页「绿色匹配决策护照」，供园区组织对接、企业询价和线下验证。

### 1.4 当前人工流程（假设，待试点访谈确认）

园区资源对接的现状（按行业常识的假设描述，试点第 1 步核对修正）：园区运营方通过临时群聊、表格和企业走访收集「谁有余料、谁能消纳」，人工比对规格与数量，撮合后由企业自行送样检测和议价。其中「供需发现」「规格比对」「方案组合」「效果核算」四处靠人工，效率低且无追溯。本系统拟嵌入的正是这四处。

## 2. 所需数据清单及脱敏要求

| 数据 | 来源 | 字段（对应模板） | 脱敏要求 |
|---|---|---|---|
| 供给批次 | 供料企业提供 | `material_supply.csv`：供给编号、物料代码/名称、聚合物类型、形态、颜色、牌号、熔指、水分、灰分、再生含量、可用质量(t)、可用时窗、产地、单价(CNY/t)、预处理方式、运输方式、因子编号、证据来源与日期 | 企业名称可用代码编号替代；价格敏感信息只保存在本机，不出网 |
| 替代需求 | 用料企业提供 | `material_demand.csv`：需求编号、目标物料代码、用途、需求量(t)、最低再生含量、熔指区间、水分/灰分上限、可接受形态与颜色、需求时窗、目的地、原生基准价(CNY/t)、最大运距(km)、证据来源 | 同上 |
| 排放因子 | 项目因子配置 | `material_emission_factors.yaml`：因子编号、阶段（原生生产/回收预处理/运输/处置）、物料代码、数值、单位、边界、地区、年份、来源与版本 | 不涉及企业数据 |
| 政策与市场背景 | 公开政策文件与公开报道 | 《参考来源.md》§2.8 已核对条目 | 不涉及 |

单位体系（计算层统一）：质量 t、单价 CNY/t、总成本 CNY、距离 km、运输因子 kgCO2e/(t·km)、材料/处理因子 kgCO2e/t。页面可格式化显示，计算层不得混用单位。

合规边界：数据只存本机 `data/input/`，系统不上传、不发邮件、不出网；试点报告对外展示使用代号与脱敏样例；企业批次数据的使用须取得试点单位与企业书面同意；因子缺失时输出待补证据，禁止用 0 代替。

## 5. 绿色指标口径（重要边界）

- 净减排必须按统一功能单位（交付 1 t 满足需方规格的合格颗粒）与同一系统边界计算：基准情景 `E_baseline = Q × 原生PP生产因子 + Q × 基准运输距离 × 基准运输因子`，项目情景 `E_project = Q × 再生PP颗粒生产因子 + Σ(分配量 × 各候选距离 × 各候选运输因子)`；成品颗粒演示不叠加「避免处置信用」；
- 替代比例为单点情景值，送样实测比例列入试点验证项；因子缺失时输出「待验证」，不输出单点伪精确值；
- 绿色溢价（边际减排成本，CNY/tCO2e）只描述方案间取舍，只称「当前系统边界下的情景边际减排成本」；
- 试点小结中的绿色结论只能写「情景测算值与实际履约的差异」，不得写「减排 X 吨」之类的成果式表述；
- 演示因子须显著标识为演示假设，真实试点前替换为经核实的适用因子。

## 6. 风险清单

| 风险 | 说明 | 缓解 |
|---|---|---|
| 规格真实性 | 供给方声明的规格与实物不一致，替代失败 | 门槛校验 + 送样检测为必经环节；替代比例以送样实测为准 |
| 供应连续性 | 批次供给是一次性的，不能证明长期稳定供料 | 把供给时窗与数量作为硬约束；组合方案避免单一供方依赖 |
| 数据授权 | 企业批次数据的敏感性与使用边界 | 试点前书面确认；本机处理不出网 |
| 因子适用性 | 材料/处理/运输因子地区与边界不匹配 | 因子带地区、年份、边界与来源元数据；缺失即待补证据 |
| 净减排重复计算 | 处置收益、再生生产因子与原生替代收益重复计入 | 同一方案只用一种分配方法；质量守恒与手算测试 |
| 场景单一 | 只做再生 PP 一类物料，扩展性未验证 | 试点先验证一类物料的闭环，再谈多品类 |
