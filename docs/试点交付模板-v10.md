# 商用试点交付模板与指标 · SPEC v10 C04

建立日期：2026-09-05。首个业务场景：再生 PP 在非食品接触工业周转制品中的替代决策。
目标付费客户假设：园区运营方或循环化改造服务商（预算归属、付费意愿仍需访谈验证，
本文金额均为报价结构假设，不编造 TAM 或合同）。

## 1. 三项可累积能力（首轮交付重点）与消融/对照

| 能力 | 消融/对照（固定其他条件） | 实现位置 | 报告方式 |
|---|---|---|---|
| 1 证据条件化决策 | 单动作只补覆盖字段 vs 全套补证（A06） | src/evidence_value.py（action 与 action_bundle 分列） | 页面「候选与证据任务」排序表：可释放供给/成本节约上限/净减排增量/服务率提升/费用/概率口径 |
| 2 可复算的多目标决策 | 完整枚举 vs 贪心（greedy_baseline）；组合 vs 单供 N-1；补证前后 N-1（A05 两张对照） | src/material.py / src/greedy_baseline.py / 站点与工作台 | 统一账本 + option_id 对齐的表格/Pareto/护照 |
| 3 反馈资产 | 规则检索 vs 名称检索（召回负例/误召回统计） | src/material_match.py 基准双任务 + 反馈表（templates/review_feedback.csv 与工作台反馈页） | 反馈统计只读、人工校正规则；样本≥20 且时间切分保留集有增益才谈学习模型 |

学习模型边界：只有样本足够且在时间切分保留集上有增益，才上线；当前先用透明统计和人工可校正规则。

## 2. 试点指标（每项写分子分母、起止事件、数据来源、缺失处理；样本不足显示不足）

| 指标 | 分子 / 分母 | 起止事件 | 数据来源 | 缺失处理 |
|---|---|---|---|---|
| 首轮决策耗时 | 需求创建→选定方案 的时间 / 任务数 | 任务创建 / 方案选定（selections 表时间戳） | runs/selections 表 | 未选定不计入，标注进行中 |
| 人工复核量 | 人工改动的供给行数 / 导入行数 | 导入体检（issues）与后续修正 | 导入预览 + 审计日志 | 无修正记录时显示 0/未发生 |
| 有效送样比例 | 送样通过数 / 送样总数 | 反馈 decision=通过 / 全部送样记录 | feedback 表（现实观察） | 样本<10 显示「样本不足」 |
| 证据关闭时间 | 证据任务创建→passed/failed 的时间 / 任务数 | evidence_tasks 时间戳 | evidence_tasks 表 | 未关闭不计入 |
| 按期交付率 | 按期交付批次数 / 已采购批次数 | feedback 交付记录 vs 合同交期 | feedback 表（现实观察） | 无现实采购记录显示「尚无」 |
| 预测/实际成本偏差 | (计划到厂成本−实际履约成本)/计划 / 任务数 | 选定方案账本 vs 履约反馈成本 | cost_ledger + feedback | 缺实际成本不计入 |
| 可复算率 | 可复算方案数 / 全部方案数 | 账本行齐备（无缺价/缺因子阻断） | options 的 computable/problems | 阻断项如实列出 |

## 3. 报价结构假设（金额与付费承诺待客户验证）

- 实施/配置：一次性（数据契约适配、规则配置）——金额待访谈
- 培训：按次/按人——金额待访谈
- 维护：按月（版本升级、因子表更新）——金额待访谈
- 软件服务：园区年度服务费或按任务计费——金额待访谈

## 4. 试点范围与验收清单（客户侧）

- 范围：一个园区、一个非食品接触用途、一个用料企业、3–10 个候选批次起步。
- 验收：完成第 2 节全部指标的完整数据闭环；备份恢复演练；角色权限符合客户组织分工；
  运行手册、故障处理、容量/并发限制见发行包《商用试点手册》。
