# 创新与壁垒

> 用途：答辩材料依据。严格区分「当前已经实现」「未来需要真实数据验证」，不虚构成绩。

## 一、核心方法：有证据约束的多目标绿色供需匹配（已实现）

围绕再生材料替代任务，把八个环节放进同一条可审计数据链：

1. **双边约束**：需求方规格（材料/形态/颜色/熔指/水分/灰分/再生含量/数量/时窗/距离上限）与供给方批次指标逐项三态判定（通过/不通过/未知）——缺证据的供给进入待核验，不因缺数据被淘汰也不默认通过；
2. **批次级物料契约与证据护照**：供给/需求/因子三份数据契约，统一单位（t、CNY/t、kgCO2e/t、kgCO2e/(t·km)），因子带边界、地区、年份、来源与版本；方案、门槛判定、因子与证据来源打包为 JSON Schema 可校验的决策护照；
3. **守恒净减排**：质量守恒（交付 1 吨合格颗粒）+ 基准/项目双情景逐项相减，每项可展开手算；替代比例为单点情景值，实测替代比例列入试点验证项；
4. **组合供料前沿**：离散步长完整枚举 → 非支配筛选 → 稳定截断（feasible/frontier/returned/is_complete 全部可验证）；
5. **证据价值排序**：对每个待核验批次构造保守/有利双情景反事实，输出「补哪项证据最可能改变决策」的价值区间；检测费用未知时只写「待询」，不输出伪精确 ROI；
6. **N-1 断供压力测试**：逐家模拟断供并重分配，输出最低交付服务率与单点故障——「低价脆弱 vs 略贵抗断供」可量化对照（演示：53% → 补证据后 100%）；
7. **结论稳定性核查**：对基准运输距离 ±20%、再生因子 ±10%、运输因子 ±10% 共 6 个确定性扰动重算全部方案，净减排方向与入选集合的翻转点如实报告，不加工；
8. **履约反馈闭环**：人工反馈 CSV 校验、分歧矩阵与规则复盘建议（只读，不自动改权重）。

Pareto、HHI 都是公开方法；创新在于把它们用于再生材料替代任务，并与三态门槛、证据价值排序、批次级证据护照、守恒反事实、N-1 压力测试与结论稳定性核查放在同一可追溯链路中。证据：`src/material.py`、`src/evidence_quality.py`、`src/greedy_baseline.py`、`tests/`（全量通过）、演示报告与仪表盘。

## 二、可复制部分与真正难复制部分（如实区分）

**容易复制的部分**：离线单文件仪表盘、基础公式（质量×距离×因子）、加权评分与 Pareto 筛选、CSV 导入。

**真正难复制的部分（潜在壁垒，当前只有验证路线）**：

| 壁垒 | 当前状态 | 验证路线 |
|---|---|---|
| 物料兼容规则（什么再生料能替什么用途） | 演示规则集 | 试点中积累检测结论 → 规则版本化 |
| 区域供需网络（谁有余料、谁能消纳） | 演示样例 | 园区试点发布真实批次 → 网络效应 |
| 因子校准（本地再生工艺/处置的真实排放） | 演示假设因子 | 接入国家因子库/园区实测 → 版本管理 |
| 人工反馈与规则迭代记录 | CSV 契约 + 只读复盘 | 真实审核积累 → 分歧率下降 |
| 替代比例实测 | 单点情景值（演示） | 送样检测 → 实测比例（试点验证项） |

壁垒形成顺序：先用规则和公开因子跑通 → 再用真实结果校准 → 再形成跨企业难复制的数据网络效应。没有实际积累的部分写成验证路线，不写成既有成果。

## 三、可审计、可替换、可复现（已实现）

- 数据契约与来源分级（README 字段表 + 因子版本）；
- 相同输入得到相同结果（确定性排序、候选顺序不敏感，有测试）；
- 净减排可手算复核（测试用独立公式对齐）；
- 报告、仪表盘共享同一结果对象；
- 本地离线运行，企业数据不上传；
- 规则升级可重放：改配置/因子版本重跑即得新结果。

## 四、演示验收场景（demo 已覆盖）

- 完全匹配的供给直接进入方案（SUP-01）；
- 数值无检测报告支撑的供给进入待核验、不进方案（SUP-02）；
- 熔指超范围被硬门槛淘汰（SUP-03）；
- 距离过远供给合法但不优：净减排下界更低、绿色成本更差（SUP-04）；
- 组合供料可行方案全部落入非支配前沿（枚举完整，方向显式配置）；
- 边际减排成本为负（省钱的减排）可手算验证；
- 保守/乐观口径真切换：待核验批次补证据后进入组合，N-1 服务率 53% → 100%；
- 结论稳定性核查：6 个确定性扰动下净减排方向与入选集合零翻转。
