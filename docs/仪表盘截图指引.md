# 仪表盘截图指引

仪表盘是单个自包含 HTML 文件（`output/` 下文件名含「供需透镜仪表盘」），断网可直接打开，不需要任何前端工具或浏览器插件。

## 打开方式

双击 HTML 文件，或用 Edge/Chrome 打开。页面不发起网络请求，离线环境行为一致。

## 截图步骤（Windows）

1. 按 F11 进入全屏（再按一次退出）；
2. 按 Win+Shift+S 框选截图；
3. 在截图提示条里选「另存为」，存为 PNG 放入材料文件夹。

## 建议截四张

1. **页眉 + 板块 1 采购关系网络**：先点击一个节点，让右侧详情面板显示企业画像和采购记录；
2. **板块 2 样本结构**：两张集中度卡片（中标方/采购方）同屏；
3. **板块 3 低碳替代情景**：完整对比表格 + 下方排放因子表；
4. **板块 4 证据与可信度**：公式、口径边界和数据来源状态。

## 注意事项

- 页眉的「演示数据」提示框必须保留在截图里，答辩时主动说明数据性质；
- 浏览器缩放建议 100%～125%，避免表格被裁切；
- 若截图用于 PPT，建议统一 16:9 选框，四张图尺寸一致。
