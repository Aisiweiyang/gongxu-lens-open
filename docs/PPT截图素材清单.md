# PPT 截图素材清单（演示素材包）

- 用途：为 1000 字介绍与路演 PPT 提供系统真实截图位；按本清单截图后直接贴入 PPT
- 编写日期：2026-09-03（按 v7 交付状态更新）
- 截图来源（四件套，全量测试通过，**现在可直接截图**）：`python -B run.py --industry 再生PP --data-mode demo` 生成 `output/再生PP供需匹配与净减排决策_20260903.md/.html`、`output/再生PP绿色决策仪表盘_20260903.html`、`site/index.html`；本地网站用 `python -B serve.py --port 8765` 后访问 http://127.0.0.1:8765/ 截图
- 所有截图都带「演示数据」标识，PPT 里不必再次声明，但不得裁掉标识。

## 通用截图要点

1. 浏览器窗口调整到 16:9（如 1600×900），滚动条滚到目标板块顶部再截；
2. 一张截图一个论点：截板块不是截整页；
3. 数字清晰优先：缩放到能看清表格数字再截；
4. 命令行动作截终端窗口文字即可；
5. 文件名按「编号-内容.png」保存到 `output/ppt素材/`（可自建）。
