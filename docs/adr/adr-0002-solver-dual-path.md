# ADR-0002：求解器双路径——穷举兜底 + 精确前沿互验

状态：已接受（v13 引入 CP-SAT 互验；v14 升级为完整前沿直接后继搜索；v16 任务 5 补记）。

## 背景

组合选料（多供给 × 0.5t 步长）在超小规模可穷举、中等规模组合数爆炸
（12 供给 ≈ 4.8×10¹⁰）；赛事与试点场景都要求「结果可复算、可向评审解释」，
且引擎改动受红线 3 约束（优化前后数值逐位一致或等价论证 + 穷举互验）。

## 决策

- 主路径：确定性精确算法——v13 为三锚点（lexicographic），v14 升级为完整三维
  非支配前沿（数学分解 + 二维前沿「直接后继搜索」逐点推进，见 src/material.py
  注释与 docs/archive/process/自审-v14.md 任务 2）；触达 FRONTIER_CAP=500 如实截断并标注
  is_complete=False。
- 互验路径：OR-Tools CP-SAT（Apache-2.0，WSL 用户 site 安装）做三锚点交叉验证；
  测试套件以独立穷举为第三方法（docs/独立核验脚本-v10.py 1 个演示案例 + 6 组随机案例 + 随机案例
  前沿集合相等断言）。
- 未安装 OR-Tools 的环境（如 Windows .e2e-venv）：贪心可行解回退，如实标注
  「未证实最优」，不伪装一致。

## 后果

- 正面：任意规模输出完整前沿（不止三锚点）；三条独立方法互相锁值，答辩可出示
  「穷举/CP-SAT/主路径逐位一致」证据；耗时换完整性（12 供给 5.5s、30 供给 19.2s，
  见 benchmarks/求解基准-v14.md）。
- 负面：求解从毫秒级升为秒级；CAP 截断的规模边界需要文档如实标注；两条路径
  并存要求测试持续看护等价性（tests/test_v13_solver.py + test_v14_frontier.py）。
