# ADR-0003：减排区间不进决策护照

状态：已接受（v14；v16 任务 5 补记）。

## 背景

v14 实现了确定性区间传播（因子 value_min/value_max 极值传播，非统计置信区间），
选项层输出 `net_interval_kgco2e`。是否把区间写进决策护照（schema v2.0.0，已随
赛事材料冻结）存在口径风险：区间语义易被读成「统计置信区间」，且已提交材料的
数值锚点（83,025 / 64,182 / 21,072.98）不容任何变动。

## 决策

- 护照 schema v2.0.0 冻结不携带区间；区间只在选项层（结果 JSON、v15 可视化
  interval_svg）呈现，且必须伴随「非统计置信区间」注记（红线 7）。
- 待「口径 v2」启动（复赛后或客户试点需要时）再设计护照 v2.x 的区间字段与
  下游渲染，届时重新评估。

## 后果

- 正面：已提交材料数值冻结不被触碰；避免把确定性极值传播误读为统计断言；
  区间能力仍可用（选项层 + 图表），为答辩留展示面。
- 负面：护照与结果 JSON 的口径暂时不一致（护照无区间）；下游（试点客户）若要
  区间需等口径 v2——已在 docs/archive/process/自审-v14.md 遗留项登记。
