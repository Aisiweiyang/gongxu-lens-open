# 市场痛点与服务蓝图

- 编写日期：2026-09-03
- 唯一首要付费客户：工业园区管委会、园区运营公司或循环化改造服务商。企业采购、工艺、供料人员是使用者，不把所有角色写成客户。
- 口径：公开来源只能证明行业层问题，不能代替客户访谈；未访谈验证的假设一律单列「待访谈确认」，禁止写成已验证。

## 1. 六个真实决策障碍与公开依据

| # | 决策障碍 | 公开依据（核对程度） | 对应功能 | 验证指标 |
|---|---|---|---|---|
| 1 | 不是找不到材料名称，而是不敢替代：聚合物类型、熔指、杂质、水分、灰分、颜色、添加剂和用途限制决定能否上产线 | 工信部 2025 目录专家解读（2025-09-30，原文核对）：「注重精细化分拣与高值化利用……瓶片料纯度高于 99%」——规格与纯度是行业公认关键；Spherity 论文（README 原文核对）列出塑料再生市场信息缺口：纯度、技术规格、添加剂、颜色、可用数量/时间、检测证据 | 分阶段召回 + 规格硬门槛 + 批次证据护照 | 候选召回率、硬门槛误放行数、人工复核量 |
| 2 | 批次质量和供货时点不稳定：单批量、可用时窗、长期稳定性难同时满足 | 《国务院办公厅关于加快构建废弃物循环利用体系的意见》（国办发〔2024〕7号，2024-02-20，原文核对）部署废弃物精细管理、有效回收、高效利用——再生供给的分散性正是该政策的治理对象 | 组合分配 + N-1 断供压力测试 | 满足需求比例、断供最低服务率、单点故障数 |
| 3 | 验证成本前置且容易花错地方：询价、取样、检测、工艺试用都要成本，平台只给候选不给优先级 | 无公开数据支撑「哪个检测最值」的量化——**待访谈确认** | 证据价值排序（价值区间 + 费用待询，不输出伪精确 ROI） | 首个可行方案出现时间、证据关闭率、无效检测次数 |
| 4 | 经济、环境和韧性同时权衡：最便宜的可能运距长、排放高或单一供方风险大 | 《企业绿色采购指南（试行）》（商流通函〔2014〕973号，2014-12-22 印发，原文核对）第五条：「经济效益与环境效益兼顾」「在满足有关环境标准、产品质量和安全要求的情况下，优先采购和利用废塑料等可再生资源」 | 同功能单位反事实 + 绿色溢价 + Pareto | 可复算率、缺因子项数、情景与履约偏差 |
| 5 | 证据分散，内部审批难：规格表、检测报告、过磅单、报价、运输和排放因子散落各处，多方难以复核同一结论 | 工信部 2025 目录解读（原文核对）强调「下游工艺匹配」与成本优化——审批所需的多源证据整合是共性缺口；具体到客户流程 **待访谈确认** | 决策护照 + 批次证据护照 | 决策准备时间、补件轮次、审阅问题数 |
| 6 | 平台冷启动和商业敏感性：企业不会为空平台持续公开价格、产能和配方 | Ellen MacArthur Foundation《Business Coalition for a Global Plastics Treaty: Recommendations for INC-2》PDF（可下载，2026-09-03 访问 200；**文本层不可直接提取，具体表述未逐字核对**——引用前须通读 PDF）；冷启动方式本身 **待访谈确认** | 园区组织的小范围、脱敏、可控数据协作（决策服务模式） | 收录批次、有效匹配、送样、试用、成交各阶段数量 |

指标口径统一说明：表中「验证指标」分两层——演示中可当场验证的四个数字（候选召回 6/6、硬门槛误放行 0、可行组合 17、断供服务率 53%→100%，由基准测试与 N-1 输出承载，见六分钟脚本）；试点业务指标以《试点验证方案.md》§4 八项为准（全部待试点数据填写），两层不混用。

**待访谈确认清单（禁止写成已验证）**：
1. 一次替代项目（从需求明确到确定方案）的实际耗时与卡点环节；
2. 谁拥有预算：园区还是企业？愿意为何种可量化结果付费；
3. 检测费用与周转时间的实际区间（用于证据价值排序的费用状态）；
4. 企业可接受的公开字段边界（价格、产能、配方哪些可脱敏发布）；
5. 下游工艺验收的真实门槛清单（与演示假设的熔指/水分/灰分阈值对比）。

**量级与缺口（谨慎口径）**：公开依据可证明行业层问题存在（上文六条），但「一次替代决策实际耗时」「无效送样比例」「园区再生料匹配缺口规模」等行业量化数字暂无已核对公开来源——报名材料只引用上表已核对条目，量化数字全部待试点实测填写（见《试点验证方案.md》§4 当前值列），不引用未核对数字。

## 2. 三类使用者分别得到什么服务

| 角色 | 他要完成的工作 | 系统提供的服务 | 成功标志 |
|---|---|---|---|
| 园区运营方（付费方） | 组织企业发布供需、推动循环化项目落地、形成可追溯成效 | 数据质量体检、跨企业候选发现、证据任务清单、组合方案、试点台账 | 从表格协调变成可跟踪任务；形成可复核的试点漏斗 |
| 用料企业采购/工艺 | 找到不影响生产的替代料，并完成询价、送样和内部审批 | 需求规格向导、硬门槛、候选短名单、证据价值排序、成本/碳/韧性对比、决策护照 | 少看无效候选；更快决定先询价/检测谁；审批材料完整 |
| 供料企业 | 让合适批次被发现，知道还缺什么才能进入采购短名单 | 批次标准化、隐私分级、适配需求提示、缺失证据清单、批次证据护照 | 有效询盘增加；减少重复填表和无效送样 |

## 3. 服务蓝图（页面动作主线）

```text
园区创建一次替代任务
→ 用料方填写用途和不可妥协规格
→ 供料方按批次发布最小必要字段
→ 系统做数据体检并召回候选
→ 硬门槛分成可行/待补证/淘汰
→ 证据价值排序生成询价、补证、送检任务
→ 对通过批次做组合、碳与断供压力测试
→ 采购/工艺人员选择方案并导出决策护照
→ 记录送样、试用、成交或否决原因
→ 园区看到试点漏斗和真实履约偏差
```

四个可操作对象：`decision_case`（一次明确用途、数量和时窗的替代任务）、`evidence_action`（责任人、对象、缺失证据、截止时间、状态和价值区间）、`decision_passport`（用于审批的方案与复算证据）、`outcome_feedback`（送样、试用、采购、否决及原因；演示值与真实值严格分开）。

演示对照：上列主线在评委网站逐段可见——数据体检与召回（s2）→ 硬门槛三态（s2）→ 证据价值排序（s3）→ 组合、碳与断供压力测试（s4/s5/s6）→ 决策护照（s7）→ 试点漏斗与八项指标（s10）。演示中证据动作按钮（待确认/已取得/不通过）的状态只保存在浏览器本地，不伪装成真实协同后台。

## 4. 痛点—功能—指标一一对应

| 痛点 | 最小功能 | 试点指标 |
|---|---|---|
| 无效候选太多 | 分阶段召回 + 硬门槛 | 候选召回率、硬门槛误放行数、人工复核量 |
| 不知道先补什么 | 证据价值排序 | 首个可行方案出现时间、证据关闭率、无效检测次数 |
| 单批量不足/断供 | 组合分配 + N-1 压力测试 | 满足需求比例、断供最低服务率、单点故障数 |
| 绿色收益说不清 | 同功能单位反事实 + 因子证据链 | 可复算率、缺因子项数、情景与履约偏差 |
| 内部审批材料散 | 决策护照 + 批次证据护照 | 决策准备时间、补件轮次、审阅问题数 |
| 园区难证明项目进展 | 试点漏斗 | 收录批次、有效匹配、送样、试用、成交各阶段数量 |

## 5. 冷启动与收费假设（全部待验证）

- 第一阶段：**一个园区、一个具体用途、一个用料企业、3–10 个候选批次**起步；园区或循环化改造服务商负责组织数据与验证动作，系统负责减少筛选与复核成本。
- 商业模式假设（未验证）：园区年度工具/服务费 + 单个试点实施服务；不开发支付、佣金或撮合聊天功能。
- 访谈验证三问：现在一次替代项目耗时和卡点在哪？谁拥有预算？愿意为何种可量化结果付费？
- 客户购买的不是「碳看板」，而是四种成本下降：①少花时间人工比对批次和规格；②少做无价值的送样与检测；③降低单一供应商断供风险；④用可复算证据说明一次材料替代的成本和绿色结果。
- 没有付费访谈或合同，不写「客户愿意付费」「商业模式已验证」。

行动闭环：上传供需 → 找到候选 → 识别阻断证据 → 决定先检测/询价谁 → 形成组合 → 输出决策护照 → 记录送样/履约反馈。
