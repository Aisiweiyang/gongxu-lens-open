# 开源项目借鉴与差异

- 编写日期：2026-09-03（按 v7 主线整理）
- 原则：只借鉴设计思想，不复制代码；不把开源能力说成自主原创；每条记录「借鉴的设计思想 / 没有照搬什么 / 本项目差异 / 许可证与引用」
- 核对方式：GitHub API 读取元数据、许可证信息与 README（只读，未下载源码）；UNTP 规范页直接打开核对

## 1. llm-lca-material-match

- 地址：https://github.com/louistrue/llm-lca-material-match
- 许可证：AGPL-3.0（1 星，最近更新 2026-02-14，Python）
- 它做什么：把 IFC 建材物料匹配到 LCA 数据库（KBOB、ÖKOBAUDAT），用嵌入向量候选召回 + LLM 重排，并带基准测试管线。
- 借鉴的设计思想：「预处理 → 候选召回 → 重排 → 基准测试」的分阶段结构；文本相似度只扩大候选、不改判结论。
- 没有照搬什么：不复制其嵌入模型、LLM 重排提示词、IFC 解析与任何代码；不引入其依赖（AGPL 传染性也要求不复制）。
- 本项目差异：场景是再生 PP 批次交易规格（聚合物类型、熔指、水分、灰分、颜色、时窗）与硬门槛，不是建筑 LCA 匹配；本项目不依赖 LLM 即可运行（确定性词典 + n-gram 基线），LLM 仅为条件式增强接口。
- 引用：设计思想层面提及，README 方法说明中注明来源即可，不逐行引用。

## 2. Google OR-Tools

- 地址：https://github.com/google/or-tools
- 许可证：Apache-2.0（13986 星，活跃维护，C++ 核心多语言绑定）
- 借鉴的设计思想：把「目标函数、约束、求解器」三者分离的结构；求解器可替换。
- 没有照搬什么：不安装 OR-Tools，不复制其建模代码。
- 本项目差异：当前演示规模（4 供给批次、0.5t 步长）用确定性精确枚举即可完整求解并手算复核，暂不需要通用求解器；但组合分配接口按「目标/约束/求解器分离」设计，未来规模扩大时可替换为 OR-Tools 等求解后端而不改上层契约。
- 引用：方法说明中提及结构借鉴；不声称使用 OR-Tools。

## 3. Brightway 与 openLCA

- 地址：https://github.com/brightway-lca/brightway2（BSD-3-Clause，136 星，Python LCA 计算框架）；https://github.com/GreenDelta/olca-app（MPL-2.0，263 星，Java，openLCA 主程序）
- 借鉴的设计思想：计算内核、数据（因子库）、因子元数据与解释层分离；生命周期数据版本化（因子带版本、来源、边界）。
- 没有照搬什么：不复制其计算内核、数据库格式与 UI。
- 本项目差异：本项目只做「材料替代净减排」的情景核算（两个情景相减 + 逐项展开），不是通用 LCA 引擎；不声称替代专业 LCA 软件——边界声明与 openLCA/Brightway 是工具互补关系。
- 引用：因子治理思想借鉴；答辩口径「不替代专业 LCA 软件」。

## 4. USEEIO

- 地址：https://github.com/USEPA/USEEIO
- 许可证：仓库根目录无许可证文件（US EPA 官方建模框架，44 星；使用前如复制内容需向 EPA 仓库确认许可，本项目不复制）
- 借鉴的设计思想：模型版本化、完整元数据、行业/产品映射与可复现输出（同一输入同一结果）。
- 没有照搬什么：不复制其投入产出模型、数据与代码。
- 本项目差异：本项目数据是批次级供需与排放因子，不是投入产出表；借鉴的是「版本+元数据+可复现」的工程纪律，落地为因子版本锁定与结果可复算。
- 引用：仅思想借鉴；不引用其数据。

## 5. Spherity Product Pass 与 UNTP DPP

- 地址：https://github.com/spherity/product-pass（仓库无许可证文件，8 星，2021 年起未更新，README 为其论文《Overcoming Information Asymmetry in the Plastics Value Chain with Digital Product Passports》）；UNTP DPP 规范页：https://untp.unece.org/docs/specification/DigitalProductPassport/（2026-09-03 打开核对，UN Transparency Protocol）
- 借鉴的设计思想：批次级证据可追溯——纯度、技术规格、添加剂、颜色、可用数量/时间、检测证据等字段清单（Spherity 论文正好点出塑料再生市场的信息缺口，也是《市场痛点与服务蓝图.md》痛点 1/5 的公开依据）；UNTP DPP 的「来源、批次、可验证证据」结构。
- 没有照搬什么：不实现区块链、DID、电子签名；不声称符合任何正式 DPP 标准。
- 本项目差异：只做轻量 JSON 批次证据护照（`schemas/material_evidence_passport.schema.json`）：schema_version、批次 ID、材料规格、来源类别、证据日期、验证状态、输入文件 SHA-256、因子与规则版本——服务于采购决策审计，不是链上存证。
- 引用：字段思想借鉴；规范页仅作参照，不称合规。

## 6. supplier-resilience-demo

- 地址：https://github.com/nabindev3/supplier-resilience-demo
- 许可证：MIT（0 星，最近更新 2026-07-11，Python，Streamlit demo）
- 它做什么：Yousefi et al. (2021) 供应商选择模型的可运行重实现，并扩展了「供应商失效后，分散采购多花多少成本、保住多少服务」的韧性分析。
- 借鉴的设计思想：供应商失效后的重优化与韧性展示——先算基准方案，再逐家模拟失效、重新分配、输出服务率与成本变化（本项目 N-1 断供压力测试的同构思想）。
- 没有照搬什么：不复制其 DEA 模型、论文实现与 Streamlit 页面。
- 本项目差异：韧性测试对象是再生材料供给批次组合；输出最低交付服务率、缺口吨数、备用方案成本与净减排变化、单点故障识别；演示含「低价但脆弱」与「略贵但抗断供」两类方案，不指定唯一最优。
- 引用：思想借鉴；答辩表述「供应商失效重优化是公开方法，本项目用于再生材料组合」。
