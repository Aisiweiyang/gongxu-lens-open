## 三、性能优化（等价变换，数值逐位一致）

| 优化 | 位置 | 方式 | 效果 |
|---|---|---|---|
| 因子解析缓存 | src/ledger.py resolve_factor | 按因子表对象身份槽 + 持有引用（防 id 复用），深拷贝场景各自独立 | 1.9M → ~150 次 |
| 净排放账本缓存 | src/ledger.py net_emissions_ledger | 同身份槽模式，键 (需求, 供给, 质量, 基准距离, 约定) | 48.4 万 → ~4.2 千次 |
| 成本账本缓存 | src/ledger.py project_cost_ledger | 按值键（成本假设与分配，与因子无关）跨敏感性场景命中 | 13 万 → ~7.4 千次 |
| option_id 缓存 | src/material.py option_id | 纯函数，键 (kind, 需求身份, 分配) | 13 万 → ~3.8 千次 |
| 敏感性枚举去重 | src/material.py run_sensitivity | 每场景 build_options 2 遍 → 1 遍 | 场景枚举减半 |
| 支配排序剪枝 | src/material.py _nondominated_mix | 预提取三元组 + 按成本升序前缀剪枝（支配者必满足 cost ≤ 目标+容差）+ 边界预计算；输出顺序保持原枚举序 | 内层闭包/字段取数消除，检查量约减半 |

结果（4 eligible 全前沿，204 方案）：WSL 49.5s → **6.0s**；Windows 178.8s → **68.2s**（同机实测）。
一致性兜底：全量 147 项测试、docs/独立核验脚本-v10.py（47 组随机案例与独立穷举完全一致）、
v12 E2E 四方数值核对（API=DB=护照逐项相等）全部通过。
