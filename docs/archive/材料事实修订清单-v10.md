## 二、措辞修订（严谨性）

1. 「断供服务率 53%→100% 证明组合优于单供」→ 删除；改为「补证使服务率 53.3%→100%（固定方案对照）；采购策略对照如实显示保守信息集下各策略均为 53.3%」。
2. 「可当场验证」数字 → 注明「演示数据下」；「召回 6/6」→「开发集 Recall@1 0.7 / Recall@3 1.0」。
3. 所有成本描述 → 注明「到厂成本（材料+运费+装卸+检测/损耗分项）」。
4. 「五维」→「八维多维」；「ROI」→「有利情景净值上限（概率未知，非 EVSI）」。
5. 站点/脚本中「57,000」「断供只剩 8t」等固定叙事数字已从生产代码删除（测试锁定）。
