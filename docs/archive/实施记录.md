## v7 轮改动（2026-09-03，赛道纯化与创新强化）

**赛道纯化**：按赛事要求把参赛项目聚焦为「绿色供应链与循环经济」原型，删除旧采购分析场景的全部专用文件（入口、配置、模板、测试与渲染分支），通用算法（三态门槛、非支配筛选、组合枚举、反馈统计）由再生材料主线独立实现；参赛目录公开交付范围全量扫描 0 条旧场景关键词。

**数学正确性**：功能单位统一为「交付 1 吨满足需方规格的合格颗粒」；供给为已造粒成品，分配质量即交付质量；基准/项目双情景显式分离（基准运输距离为配置参数，回归测试锁定其只影响基准侧）；Pareto 显式方向（成本越小越好、净减排越大越好、订单最大份额越小越好）；单供资格=一家具备全部产能，部分产能批次只进组合；任何正分配供给缺价 → 方案成本不可计算、不进成本维度 Pareto；因子治理校验（ID 唯一/字段完整/数值有限非负/等级二分）。

**数据模式**：demo 只用内置演示数据；local 必须读取两份物料 CSV，缺失或坏字段直接失败不回退；auto 优先本地否则演示并展示原因；online 未实现直接报错退出非 0。

**创新**：分阶段材料召回（同义词/字符 n-gram 召回 + 硬规格门槛）、证据价值排序（保守/有利双情景反事实 + 费用待询）、批次证据护照（JSON Schema + 输入文件哈希）、N-1 断供压力测试（交付服务率/缺口/单点故障）、反馈只读复盘。

**演示故事线**：1 条需求（15 t）× 4 条供给：8t 完全匹配（只进组合）、7t 需补检测（证据价值排序演示）、熔指超范围淘汰、18t 低价但单供脆弱（N-1 演示）。
