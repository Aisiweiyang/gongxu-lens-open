## 0. 开场（20 秒）

不是找不到材料，是不敢替代。名称相似的再生批次，规格、证据与供货能力可能完全不同。
供需透镜把「能不能替、怎么组合、净减排是否成立、还缺什么证据、先补哪个最值」
放进同一条可审计链路。

## 1. 首屏结论（20 秒）

- 最低成本方案：外省单供，到厂成本 **59,820** CNY（材料 57,000 + 运费 2,520 + 装卸 300），
  较全部原生基准 83,025 省 **23,205**。
- 保守净减排 **20,575.52** kgCO2e / 15 t（最优组合 20,843.61）；逐项可手算。

## 2. 三态门槛与召回基准（40 秒）

- 三态：可比较 / 待核验 / 不符合——缺证据不等于不合规，不被误杀也不默认通过。
- 召回基准（重定义，固定候选池 Top-k）：开发集 7 例 **Recall@1 = 0.7、Recall@3 = 1.0**；
  保留集 3 例 Recall@1 = 0.5、Recall@3 = 1.0；空查询显式拒绝；硬门槛误放行按 7 类标签
  （正负规格/临界值/缺证据/材料不兼容/时窗不符）统计 **0 例**。旧「6/6」口径为
  单候选评测，已废止并如实标注。

## 3. 证据价值排序（30 秒）

每个证据动作只补齐它覆盖的阻断字段；保守/有利双情景反事实。
排序结论：**先给 SUP-02 补检测报告**——释放 7 t 供给，与本地 8 t 组成抗断供组合。
通过概率未知时只给有利情景净值上限（非 EVSI、非精确 ROI）。

## 4. 成本 × 保守净减排 × 供应集中度（40 秒）

- Pareto 三方向显式配置：到厂成本↓、净减排↑、订单最大份额↓。
- 完整可行集 **17 个组合方案**（当前离散网格内完整枚举，独立穷举复核一致）；
  完整非支配前沿全部进入方案表，以 option_id 对齐（同名称不同分配是不同方案）。
- 保守/乐观口径一键切换：表格、Pareto、N-1、护照下载同快照联动（可往返任意次）。

## 5. 代表组合与 N-1（50 秒，两张分离对照）

- **对照一（采购策略）**：固定保守信息集下，各代表策略断供服务率均为 **53.3%**——
  如实显示组合策略本身并不优于单供，避免虚假因果。
- **对照二（补证效果）**：固定采购方案下补证使服务率 **+46.7 个百分点 → 100%**。
- 失效实体=供应商（名下批次同时失效）；切换时间/费用未知按产能上限口径标注，
  不冒充交付保证；只测单家失效（未启用共同失效模型）。

## 6. 可手算碳对照与结论稳定性（50 秒）

- 每个数字 = 活动量 × 因子：E_baseline = Q×原生生产因子 + Q×基准距离×基准运输因子；
  E_project = Q×再生颗粒生产因子 + Σ(分配量×距离×运输因子)。
- 因子按角色显式解析（不硬编码 ID）；原生 cradle-to-gate 与再生 gate-to-gate 的
  边界兼容性按核算约定显式判定，不满足即阻断。
- OAT 扰动 + 翻转阈值 + 两参数联合情景：演示数据下结论稳定；扰动范围标注为演示假设。

## 7. 决策护照与试点（50 秒）

- 护照 Schema v2：run_id/option_id、文件哈希与规范化记录哈希、完整账本 trace、
  未知项；下载绑定当前口径，JSON Schema 可校验。
- 试点闭环：一个园区、一个用途、一个用料企业、3–10 个候选批次、2–4 周；
  七项指标（首轮决策耗时/人工复核量/有效送样比例/证据关闭时间/按期交付率/
  预测实际成本偏差/可复算率）分子分母口径见《试点交付模板-v10.md》。
- 商业模式为待验证假设（园区年度服务费 + 试点实施服务），不写客户付费承诺。
