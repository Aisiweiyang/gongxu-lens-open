# 供需透镜 · 静态演示包运行手册

> 手册适用于随包 `VERSION.txt` 所示版本（包内容随每轮发行重建，本手册操作方式保持不变）。

## 一句话

双击 `site/index.html`（或复制到任意机器用浏览器打开）即可完成评委演示——单文件离线，
无外部资源、无需联网、无需 Python。

## 演示要点（六分钟叙事线）

1. **首屏结论**：最低成本方案、保守净减排、现状代表方案断供服务率与补证后对比（两张对照分开归因）。
2. **三态门槛**：可比较 / 待核验 / 不符合——缺证据不等于不合规（第 1 步筛选按钮可切换）。
3. **证据价值排序**：先补哪个检测最可能改变结论（第 3 步）。
4. **Pareto 与保守/乐观口径切换**：表格、图、N-1 三视图同一快照联动（第 4 步按钮往返切换任意次）。
5. **N-1 两张分离对照**：补证影响 vs 采购策略影响（第 5 步）。
6. **可手算碳对照**：每行 = 活动量 × 因子，逐项可展开（第 6 步）。
7. **决策护照**：下载 JSON（Schema v2 可校验），绑定当前口径（第 7 步）。
8. **企业检索 + 公开市场背景**：真实企业与演示数据严格分开（第 8-9 步）。
9. **试点入口**：商业模式为待验证假设，不写付费承诺（第 10 步）。

## 动态生成（可选）

需要 Python 3.12+ 与 PyYAML：

```bat
pip install -r requirements.txt
python run.py --industry 再生PP --data-mode demo
```

重新生成 `site/index.html` 与 `output/` 下的报告/仪表盘。演示数据全部为虚构，
不得用于真实决策；净减排为情景核算，非实测减排。

## 操作与快捷键

- 演示模式按钮：显示演讲者注释；←/→ 翻板块、空格自动播放、F 全屏；
  输入框内不拦截（企业检索框内方向键正常编辑）。
- 图点悬停/键盘聚焦（Enter）高亮对应方案行。
- 打印：自动隐藏操作控件，保留来源与数据模式说明。

## 文件清单与校验

见包内 `FILES.txt`（SHA-256）与 `VERSION.txt`。
