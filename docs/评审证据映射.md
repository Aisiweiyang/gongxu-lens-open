# 评审证据映射

- 用途：逐项对应赛事官方评审口径，链接到具体代码、测试、图表和来源，不写空泛口号
- 编写日期：2026-09-03（按再生材料主线修订）
- 评审口径出处：首届清华大学绿色创新挑战赛公开表述——项目须具备「创新性、可行性和绿色社会价值」，无知识产权争议；官方未公布量化评分细则
- 主线问答五问（材料叙事统一口径）：循环经济问题是否真实、绿色收益是否为净收益、供需匹配能否落地、客户为什么愿意提供数据、试点如何验证

## 一、创新性

| 本项目证据方向 | 证据位置 |
|---|---|
| 把替代性门槛、批次级物料证据、组合匹配与净减排核算放进同一条可审计的决策链路（如实表述：Pareto、HHI 均为公开方法，创新在于围绕再生材料替代任务建立统一数据契约与守恒反事实） | 六分钟脚本创新点段；`docs/创新与壁垒.md`；组合前沿（demo：可行方案全部落入非支配前沿，方向显式配置） |
| 净减排核算的完整边界：基准情景（Q×原生生产因子 + Q×基准运输距离×基准运输因子）减项目情景（Q×再生颗粒生产因子 + Σ分配量×距离×因子），功能单位「交付 1 t 合格颗粒」，成品颗粒不叠加处置信用 | 仪表盘净减排手算展开板块（demo：SUP-04 单供净减排 20576 kgCO2e，可逐项手算） |
| 因子缺失输出待补证据而非 0；替代比例为单点情景值，实测列入试点验证项 | 因子契约（材料生产因子为演示假设因子，运输 0.07447 为 DEFRA 2024 官方行 6293） |
| 证据价值排序：补哪项证据最可能改变决策（保守/有利两情景重跑） | 仪表盘证据反事实表（demo：SUP-02 补检测排第一，可释放 7 t → 解锁 8+7 组合） |
| N-1 断供压力测试与「低价脆弱 vs 略贵抗断供」对照 | 仪表盘 N-1 表（demo：SUP-04 单供断供服务率 53%；补证据后（乐观情景）多供方组合 100%） |
| 反馈学习只积累标注与复盘，不宣称自主学习 | `templates/review_feedback.csv` 契约与只读复盘统计 |

## 三、绿色社会价值

| 本项目证据方向 | 证据位置 |
|---|---|
| 政策依据逐条可查：国发〔2025〕14号「引导生产企业提高再生材料应用比例」「探索再生材料应用情况信息化追溯」；零碳园区通知「健全园区废弃物循环利用网络」；无废园区申报条件「固废种类、数量、流向、贮存、利用、处置信息详实准确」 | 《参考来源.md》2.8（四份政策文件均原文核对） |
| 绿色收益是净收益：材料替代与循环利用的净环境收益，不是「距离更短=更绿色」；绿色溢价（边际减排成本）只称「当前系统边界下的情景边际减排成本」 | 《参考来源.md》2.8.3；仪表盘绿色成本板块（demo：SUP-04 单供省 25500 元、净减排 20576 kgCO2e，四类分类完整） |
| 供需匹配落地路径：批次级物料护照、就近消纳、组合供料；政策数字支撑（2030 年大宗固废年综合利用 45 亿吨目标） | 《试点验证方案.md》§5/§8 |
| 不夸大：只做非危险、可标准化材料；不替代送样检测、交易撮合、固废监管；无真实成交只写情景测算 | 六分钟脚本边界段；《试点验证方案.md》§5 |

- 本文档的证据均为可打开验证的代码输出、模板契约与文档记录；代码侧证据在再生 PP 主线交付后逐条核对，不保留旧场景数字；
- 官方未公布量化评分细则，三维权重与子项以官方后续公布为准，本文件不猜测；
- 复赛路演（若入围）前由团队逐条演练验证一次。
