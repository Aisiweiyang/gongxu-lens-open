# v0 初始开源版验收（内部迭代 v27.1）

日期：2026-10-08（北京时间）。许可证由项目所有者明确选择 MIT。
本轮保留引擎算法 material-v8 与护照 Schema v2.0.0；未使用真实业务数据验证成效。

## 修复与准备

- 静态演示服务统一 GET/HEAD 路径校验，拒绝解码后的目录穿越、Windows 反斜杠与
  白名单外符号链接，禁止目录列表；错误响应不再因中文 HTTP 状态消息抛出编码异常。
  默认服务根目录固定为源码目录，与启动时工作目录无关。
- 新增 9 项静态服务与 4 项公开范围回归。
- 全流程浏览器脚本等待真实任务创建完成，备份验证实际删除供给再恢复；失败时释放
  自己创建的 Chrome。Windows 回滚测试在替换实例前关闭恢复后重新打开的 SQLite 连接。
- MIT LICENSE、第三方声明、双语安装说明、固定直接依赖版本与 CI 已加入源码；许可文件
  同步进入发行白名单。安全报告改为 GitHub 私密报告入口，发布时核验功能已启用。
- 当前独立核验口径校正为 1 个演示案例 + 6 组固定种子的随机案例；历史“47/47”不作为
  当前脚本覆盖依据。历史变更日志保留并附更正说明。
- 公开源码导出排除内部参赛/过程档案、业务输入/数据库/备份、旧生成报告、配置备份、
  第三方 PDF 原件与本地 Word/PDF 手册；原资料仍留在本地。

## 公开发布范围

项目所有者已授权新建公开仓库，正式入口为
[Aisiweiyang/gongxu-lens-open](https://github.com/Aisiweiyang/gongxu-lens-open)。
原 `Aisiweiyang/gongxu-lens` 保持私有，其 main 历史和 v18–v27 旧标签/Release
继续作为开发档案，不进入新仓库。

新仓库仅从当前公开源码清单建立一个无父提交的初始版本。双语 README 的克隆与
CI 链接、安全报告入口均指向新仓库。CI 覆盖 Linux Python 3.12/3.14，使用固定提交
版本的官方 Actions；最新线上执行结果可从 README 的 CI 入口查看。

`dist/public-source/` 与 `dist/gongxu-lens-public-source.zip` 是当前公开内容的导出产物，
包含逐文件 SHA-256 清单。具体规则与发布验收见 [开源发布指南.md](开源发布指南.md)。

尚未验证：Firefox/WebKit、真实客户/真实减排成效、macOS 安装、任何公网部署。
